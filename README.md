# SQL Project: Retail Sales Analysis

Project ini merupakan bagian dari latihan dan studi mandiri dalam penguasaan SQL untuk analisis data.

## 📁 File yang Termasuk:
- `Project_EDA.sql`: Exploratory Data Analysis menggunakan SQL
- `SQL - Retail Sales Analysis_utf.csv`: Dataset utama (versi UTF)
- `SQL - Retail Sales Analysis_utf 1.csv`: Dataset utama (versi alternatif)
- `sql_query_p1.sql`: Query tambahan lanjutan

## 📊 Tujuan Proyek:
Menganalisis dataset penjualan retail untuk menemukan insight penting seperti:
- Produk terlaris
- Pola penjualan berdasarkan kategori & waktu
- Rata-rata pendapatan per transaksi
- Analisis performa toko

## 🧰 Tools yang Digunakan:
- SQL (PostgreSQL / MySQL / lainnya sesuai kebutuhan)
- VSCode / DBeaver
- GitHub

## 🧠 Insight Utama:
> Hasil analisis dapat digunakan untuk mendukung keputusan strategis dalam bidang penjualan dan pemasaran.
